EP.001 / 工作与睡眠

下班后，还要追多少个 AI？

十一点半，收藏夹又多了一条教程。聊聊睡眠、消息与那个总觉得自己还不够努力的晚上。

TRANSCRIPT本期文稿his.fm
一段声音的起点

你可能有过这样的晚上。十一点半，工作群里又出现一个新工具的演示。你点开，想着就看十分钟，至少知道别人说的是什么。视频看完，又顺手打开教程。等到准备睡觉，收藏夹多了几条，明天的工作没少，心里倒多了一件事：这个也得学。

这里是 his.fm。今天聊一个放在 GitHub 上的项目，叫 How To Live Better，中文名是《高性价比人生指南》。我读到的版本有三十三章、六百零三条建议。我们从里面挑出睡眠、注意力和放松，看看它们和那个深夜还在补课的你，有什么关系。

作者在首页先交代了一件事：这些只是备选，挑走一两条就算数，他自己也没做到其中大部分。每条都写成本、收益、证据和备注，连需要多少毅力也算成本。这个细节值得留意。下班后终于坐下来的人，未必还剩一份充足的毅力。

项目的在线页面可以按关键词查，也可以按时间、毅力和证据等级筛选。读它不必从第一页开始。比如，眼下最困扰你的是，白天忙了一整天，晚上学不进去，那就沿着这个问题找。

第三章引用了一项二〇〇三年发表在《睡眠》期刊上的实验。整个研究有四十八名健康成年人，二十一到三十八岁。其中，持续限制睡眠的参与者，被随机安排每晚四小时、六小时或八小时的卧床时间，连续两周，其他时间不许补眠。研究者反复测他们的认知表现，也让他们报告自己有多困。

四小时和六小时组的表现，随着天数累积，越来越差。但他们自己报告的困倦，头几天上升以后，后面增加得就很少了。主观上好像适应了，测出来的表现却没有跟上。

这项实验没有测写代码的效率，也不能替你判断个人需要睡多久。它说明，自觉还能撑，未必能准确反映持续少睡的代价。当你凌晨重看同一段教程，仍然读不进去，睡眠也是一个值得排查的变量，先别急着把原因归到能力上。

当然，知道这个，不会让明早的交付自动延期。如果团队要求掌握一个新工具，可以把问题问具体：哪项工作需要它，什么时候真的用，练习和验证要安排在哪段时间。否则，“跟上变化”没有终点，只能不断从夜里借时间。

比如，下周要用它整理会议记录，就先明确怎样才算做好：重点有没有漏，分给谁的事情有没有写错，最后谁来复核。把这些要求说清，学习才有停下来的位置。若要求只是“新东西都要了解”，再多几个夜晚也很难填满。

还有一种累，发生在睡前很久。你刚想好一段代码怎么改，消息来了；回复完，顺手看一眼新模型的介绍；再回来，得重新想自己做到哪里。刚才那点思路已经散了。

第三章里，有一项二〇一五年发表的邮件实验。研究最终分析了一百二十四名成年人的情况。两周里，同一个人要经历两种安排。一周尽量每天只查三次邮件，其余时间关闭邮箱和提醒；另一周则让邮箱开着，开启提醒，尽量频繁查看。先经历哪一种，随机决定。

减少查看的那周，参与者报告的日常压力平均更低。两周收到和回复的邮件数量，研究没有发现显著差异。改变的是查看的节奏，邮件并没有因此消失。这项结果谈的是自报压力，不能拿来保证工作效率。

还有个很实际的细节：要求每天三次，并非人人严格做到。限制那周平均查看接近五次，另一周大约十三次。研究并没有证明三次就是最佳次数，更没有要求你照着这个数字生活。

它有个不能省掉的前提：参加的人，本来就有一定自由决定什么时候查邮件。需要实时回应的工作，照搬起来就不一样了。而且，邮件研究也没有直接验证今天的工作群。

所以，若想借用这个思路，可以先和同事约好一段连续工作的时间，说明什么时候集中回复，急事怎么找到你。比如约定“我先连续看完这份文档，十点半统一回复”，就比一句“今天少看消息”更容易让别人配合。试过之后，再看看是否让协作更顺畅，哪里还需要调整。如果别人仍按随时在线来安排工作，只在自己手机上关掉通知，会留下新的沟通问题。回复节奏要能共同配合，才能少一点“是不是漏了什么”的惦记。

至于学习，可以先找出这周确实需要解决的一件小事。假设你想用 AI 给反馈归类，自己编十来条示例，放进两条措辞不同、意思相近的内容，再加一条容易分错的，看看工具怎么处理。关掉教程，重做一次；哪里不对，就记下具体卡在什么地方。

这个小练习是顺着项目想到的一种做法。把工具分错的那条反馈单独留下，写清楚你原本怎样判断，下次再试时先检查这一条。这样，至少有机会分清，是提示还没说清，还是工具一直没能处理好这个问题。下次查资料，也就知道从哪一步开始。

看到演示里结果出现，很容易觉得任务已经完成。到了自己的工作，还要核对有没有漏项，前后标准是否一致，别人能不能接着用。生成得快，只是整个流程里的一段。检查这些内容仍然需要人的注意力，把它们也放进学习时间，才不会误以为点一下就该全部完成。

不过，空出来的一点时间，也可以先留给晚饭。

有时电脑已经合上，人还停在工作里。脑子继续排明天的事，手机放在桌上，吃两口就看一眼。第二十二章谈放松，其中一条引用了二〇二三年的呼吸练习研究。

这项研究把一百多名成年人随机分到几组，要求每天练习五分钟，持续一个月。有人练不同的呼吸方式，有人做同样时长的正念练习。其中一种叫循环叹息，特点是吸气分两段，呼气拉长。研究发现，这组在每天练习前后，自报积极情绪的改善，比正念组更明显。

读到这里，先别急着把它存成新的必做事项。原项目把三种呼吸练习概括为都优于正念；回到论文逐组比较，另外两种在积极情绪上的优势，并没有达到统计显著。研究人数不多，只有四周观察，也没有拿散步、听歌或发呆来比较。

它提供的是一种短时练习的初步证据，还排不出一张适合所有人的休息排行榜。你可以继续了解这种练习，也可以先用自己熟悉的方式，给工作和晚上的生活留一个分界。

比如，吃饭的时候把手机放远一点。朋友说起今天的事，就先听完，不用顺手再开一段教程。这样的安排不必再附上一句“这样明天才能更高效”。这顿饭和这段谈话，本来就是今晚要过的生活。

这也关系到我们怎么读《高性价比人生指南》。

它把许多零散问题放到了一起，留下原始来源，方便继续查。但证据等级和建议的排序，是两件不同的事。项目的 A、B、C 是自己的分类；同样标着 A，研究方法和适用人群也可能不同。如果只是观察到两件事经常一起发生，就还不能断定照着做一定有效；即使做了随机实验，也得看实验让人改变了什么。作者也明确说，性价比那一档是他的判断，本身不是证据。

比如，表格把一件事标成“时间少”，可能确实只要五分钟。但你得记住它，挪出时间，连续做下去。如果晚上唯一空着的半小时，已经约好和朋友聊聊，这五分钟就得放回那个晚上重新考虑。表格看不到你的日程。

所以，我会连着读完一条建议和它的备注：研究里的人是谁，实际比较了什么，自己的生活有没有相应条件。邮件实验里的安排自由，就是这样的条件；呼吸练习里的四周观察，也是边界。只看标题，很容易把一个有限的结果听成了人人都该做的事。

如果听完想打开这个项目，可以直接在检索页搜“睡眠”或“邮件”，读一条，顺着来源往下看。六百多条内容可以留在那里，下次有具体问题，再回来。

至于今晚还没看完的教程，先记下卡住的那一步，再关掉页面。明天需要继续时，就从那里接着来。
