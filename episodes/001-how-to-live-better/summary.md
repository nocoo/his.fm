# 下班后，还要追多少个 AI？

his.fm · 第 001 期 · 中文单人播客 · 预计约 10 分钟

## 发表摘要

新工具的教程还没看完，下一轮更新已经来了。这一期借 GitHub 项目《高性价比人生指南》，从睡眠、刷资讯和换工作的具体难处聊起。我们回到一项持续两周的睡眠实验、一次停用 Facebook 的随机实验，以及一宗索赔七百一十万元违约金的竞业限制案，看看那些听起来简单的建议，有多少证据，又有哪些条件。也聊怎样把“这个也得学”变成一个具体问题，以及转型前容易漏查的协议与保障。

## 收听提纲

- 夜里又打开一段教程：一份生活指南会不会变成新的考核表？
- 连续两周限制睡眠，为什么自觉困不困和实际表现会分开？
- 合上材料做一次小练习，比继续收藏多知道了什么？
- 停用 Facebook 后，有人多陪家人，也有人多看了电视；少刷资讯确实有得有失。
- 七百一十万元的竞业索赔案：同在一个行业，限制究竟应该画到哪里？
- 换工作之前，留好哪些材料，去哪里核对失业期间的医保安排？
